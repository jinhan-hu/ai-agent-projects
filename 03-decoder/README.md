# 03 · 号码解码引擎

面向大规模脱敏通话数据的离线还原工具，**零第三方依赖**（纯 Python 标准库）。

## 问题

外呼平台导出的明细表中，手机号以 32 位 MD5 哈希存储。需要批量还原为明文，用于数据核对与质量审计。

## 模块划分

| 模块 | 职责 |
| --- | --- |
| `parse/` | 流式 XML 解析：单遍读取 500MB+ 单表数据 |
| `index/` | 哈希集合构建：24 万条唯一哈希，O(1) 查表 |
| `crack/` | 16 进程并行穷举约 70 亿候选空间，边算边查 |
| `verify/` | 运营商号段 + 归属地交叉校验，确保零错解 |
| `write/` | 流式回写：保留原始 32 列并新增解码列 |

## 关键设计

- **边算边查（等效彩虹表）**：不预先生成全量映射表，而是边计算候选、边与哈希集合匹配，大幅降低内存占用
- **16 进程并行**：按 CPU 核心数切分候选区间，进程用完即弃
- **流式处理**：全程无全量内存加载，500MB+ 大表单遍读写；配套 zip 完整性与 SHA-256 双重校验
- **交叉校验**：还原结果必须同时满足运营商号段与归属地字段，排除哈希碰撞导致的错解
- **零依赖交付**：纯标准库脚本套件 + 图文操作手册，普通员工按三步即可复现

## 结果

24 万条记录 **100% 精确还原**，端到端约 44 分钟。

> 代码为脱敏后的结构示意，不含业务逻辑与客户数据。
