# 02 · 通话语音转写系统

基于 faster-whisper 的通话录音转写与分析系统，部署于 **纯 CPU、2GB 内存**的阿里云生产环境。

## 模块划分

| 模块 | 职责 |
| --- | --- |
| `watch/` | inotify 目录监控：自动发现新上传的 wav |
| `queue/` | 阻塞队列：生产者–消费者解耦 |
| `asr/` | faster-whisper medium（INT8 量化）+ 多线程推理池 |
| `segment/` | 多策略断句：VAD + 标点 + 语气词停顿 |
| `output/` | 结构化文本输出（含热词替换后处理） |

## 关键设计

- **INT8 量化**：FP16 → INT8 权重压缩，内存占用降低约 **50%**
- **模型常驻内存**：启动时加载一次，消除「请求–加载–推理–卸载」的重复开销
- **生产者–消费者**：监控线程入队、推理线程池消费；结合多线程调度将吞吐显著提升
- **热词增强**：可配置权重 + 后处理替换规则，提升业务术语识别准确率并抑制幻觉
- **双声道分离**：ffmpeg 分离客户/客服声道并统一重采样到 16kHz

## 结果

单通数分钟录音处理压缩至 **约 30 秒**，部署于阿里云 Linux 稳定运行。
