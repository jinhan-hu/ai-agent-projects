# 01 · 智能销售 Agent

基于 LangGraph 的多智能体销售助手。售前 / 售中 / 售后三个阶段由"总指挥官"判定并路由到对应专家 Agent。

## 模块划分

| 模块 | 职责 |
| --- | --- |
| `orchestrator` | 总指挥官：阶段判定 + 置信度评分 + 路由 |
| `experts/` | 售前 / 售中 / 售后三个专家 Agent |
| `rag/` | 混合检索（向量 + BM25）+ 企业画像 |
| `memory/` | 两级存储：客户长期档案 + 会话短期记忆 |
| `api/` | FastAPI + SSE 流式接口 |

## 关键设计

- **置信度阈值 0.9**：低于阈值触发兜底，避免错误阶段流转
- **混合检索**：纯向量在垂直业务术语上存在语义漂移，加入 BM25 补精确匹配
- **两级记忆**：长期档案与会话记忆生命周期不同，分开存储

> 代码为脱敏后的结构示意，不含业务逻辑与客户数据。
